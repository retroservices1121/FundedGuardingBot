# Funded Guardian public pages

The Railway backend serves the public site at fundedguardian.xyz. The legal pages and their stylesheet live in [public/legal](../public/legal).

## Public URLs

- Landing: https://fundedguardian.xyz/
- Privacy: https://fundedguardian.xyz/privacy
- Terms: https://fundedguardian.xyz/terms
- Support: https://fundedguardian.xyz/support

The beta button forwards to the existing Railway signup page to preserve its email capture and immediate TestFlight link. Privacy/terms describe the current Guardian implementation; update them if processing or operator contact details change. Project support currently uses the existing Telegram project contact and public GitHub issues for non-sensitive technical reports. Do not post personal data or API keys in an issue.

Connect the final published privacy and support URLs in App Store Connect and the app's settings before production distribution. A terms URL on a site does not itself add an in-app acceptance flow or replace platform agreements.
