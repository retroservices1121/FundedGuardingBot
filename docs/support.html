Support

Help with Guardian on iOS and Telegram.

Effective October 20, 2026

Get started

Join the iOS TestFlight beta or open the Telegram mini app. Connected trading requires an active MyFundedPerps account and an API key you are authorized to use.

Connection or trading trouble

Check that your API key is valid and the account is active. If a request has an uncertain result, check positions and orders directly in MyFundedPerps before retrying. Never include API keys, passwords or session tokens in screenshots or messages.

Notifications

Allow notifications in device settings, enable the categories you want in Guardian Settings and save your choices. News and alerts require a network connection and can be delayed.

Delete or disconnect

In Guardian Settings, use Disconnect API key or Delete Guardian account. Revoke a key directly in MyFundedPerps if you want its platform access removed. Guardian deletion does not close positions or delete your MyFundedPerps account. Read the Privacy Policy for separate Telegram and website records.

Contact

Project contact: @fundedguardianbot on Telegram. For non-sensitive technical reports, you can also use the project issue tracker. Include your app version, device type and the steps that caused the issue. Request a private follow-up for account or privacy matters; do not post personal account details publicly.
