Connect your challenge

An API key lets Guardian read your account and submit trades you confirm. You only need to connect once.

  1. Sign in to MyFundedPerps

    Use the account that owns your challenge.

  2. Open Settings → API Keys

    Create a new key and name it “Funded Guardian”.

  3. Choose the access you need

    Allow access to the challenge accounts you want to use. Trading requires trade permission; a read-only key cannot place orders.

  4. Copy your key

    The secret is shown once. For your regular challenge, use your live key beginning fp_live_. Sandbox keys begin fp_test_.

Official API key guide ↗
